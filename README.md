# CreatorHub

**Interactive Content Studio** — stories, quizzes, code playground

## Live Demo
**[https://crowfly22.github.io/CreatorHub/](https://crowfly22.github.io/CreatorHub/)**

## Features
- **Story Mode**: branching narrative creator, scene editor, choice system
- **Quiz Mode**: multiple choice + true/false, timer, leaderboard, scoring settings
- **Code Mode**: HTML/CSS/JS editor, live preview, console output
- 7 templates (Fantasy Adventure, Mystery Detective, Sci-Fi Explorer, Science Quiz, Coding Challenge, Landing Page, Snake Game)
- Share via URL
- Export as HTML

## Multi-Agent Architecture
- **Story Agent**: branching narrative flow, scene graph validation, tree visualization
- **Quiz Agent**: question generation, scoring logic, performance analytics
- **Code Agent**: syntax checking, live preview rendering, console output
- **Export Agent**: URL sharing, HTML export

## Tech Stack
- Vanilla JavaScript
- CSS Glassmorphism
- iframe sandbox
- Zero dependencies
